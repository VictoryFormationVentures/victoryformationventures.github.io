Install in Gmail

1. Click Copy signature above.
2. In Gmail, open Settings (gear) → See all settings → General tab → scroll to Signature → Create new, give it a name.
3. Click inside the signature box and paste (Cmd+V). The logo and layout come through as-is.
4. Under Signature defaults, set it for new emails and replies, then Save Changes at the bottom.

On the Gmail phone app, signatures are text-only, so this one applies to mail sent from a computer. Apple Mail and Outlook accept the same paste.
